# MedStudy: instruções para o Claude Code

Plataforma de estudos de Medicina em português do Brasil. Especificação completa em `docs/PROJETO.md`.

## Regras
- Trabalhe por etapas (seção 25 do PROJETO.md). Depois de cada etapa: o que foi feito, arquivos alterados, testes executados, pendências e o que depende do usuário.
- Nunca invente credenciais, editais, questões ou referências médicas.
- Nunca exponha chaves secretas no frontend. Todas as tabelas com RLS.
- Não apague arquivos nem funcionalidades sem analisar o impacto.
- Não diga que algo foi testado se o teste não foi executado.
- Interface em pt-BR, datas dd/mm/aaaa, valores em R$.
